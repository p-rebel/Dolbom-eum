## 해야 할 일

1. NHIS 원본 CSV를 수정 없이 보존하고 정제본을 별도 생성했다. 행 수 90,081 유지.
2. 지자체 메뉴판 PDF 234개에서 표를 추출했다. 원본 대조 51,209개 값 조각에서 새 불일치 0건 (`logs/pdf_nationwide_final_report.md`).
3. 두 데이터를 각각 정제했다. 공백·제어문자 정리, '-' → 공란만 적용
4. 지역명을 표준화했다. 원본 칼럼(`*_raw`)과 표준 칼럼을 분리했고, 개편 관련 값은 바꾸지 않고 상태 칼럼으로 표시했다.
5. 중복은 삭제하지 않고 표시만 했다 (`duplicate_group_id`, `is_duplicate_extra`).
6. 검토 결과를 반영했다.
   - 장흥 합쳐진 사업명 1행을 PDF 칸 경계를 재확인한 뒤 5행으로 분리했다 (12,721 → 12,725행).
   - 인천 개편 전 메뉴판 3문서는 문서 단위로 지역 미확정 처리했다.
   - 행별 `review_severity`·`review_status`를 부여했다.
7. v1.4 CSV에서 실제 행만 골라 샘플 JSON 3종을 생성했다. 가상 데이터는 넣지 않았다.
8. NHIS–PDF 서비스 매칭은 설계·파일럿까지만 진행했다. 정제 데이터에서 두 데이터는 병합하지 않았다.
