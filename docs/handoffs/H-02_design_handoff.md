## 인수 회의

1. 김재현·양이수가 C-01을 단계별로 따라가며 API 응답과 화면값을 비교한다. 같은 초안에서 읍면동과 시군구의 편집 동작이 어떻게 다른지 확인한다.
2. 김예랑은 가상 판정, 회의 확정과 안내일 분리, C-06의 기존 제공 현황과 모니터링 관찰을 확인한다. 이보미는 공단 행 ID와 출처·기준일, 결측과 지역·분류 조회 기준을 대조한다.
3. 이동수는 DEC-01~05와 DEV-01~09의 담당·기한을 정리한다. 5명이 각자 넘길 결과·받을 사람·완료 기준을 확인하고 남은 조건을 아래 표에 기록한다.
