# 정책 참고 이미지

사용자가 제공한 보건복지부 통합돌봄 누리집 화면 캡처를 원본 그대로 보관한다. 제품 화면 시안이 아니라 공식 정책·업무를 이해하기 위한 참고 자료다.

캡처는 자료 제공 당시 화면이다. 정책과 서비스 목록은 원문에서 최신 내용을 다시 확인한다. 이미지 속 개별 서비스의 수·명칭·지원 조건을 프로젝트 구현 범위로 확정하지 않는다.
