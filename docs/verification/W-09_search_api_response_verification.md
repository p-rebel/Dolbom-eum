## 3. 검증 요약

| 구분 | 전체 | 통과 | 실패 | 보류 | 미실행 |
| --- | --- | --- | --- | --- | --- |
| 기존 테스트 `test_catalog.py` | 28 | 28 | 0 | 0 | 0 |
| 표본 상세 조회 | 15 | 15 | 0 | 0 | 0 |
| 검색·필터 조건 | 23 | 23 | 0 | 0 | 0 |

- **기존 테스트와 이번 검증의 관계:** 기존 테스트는 적재 건수, 422 처리, 로그인 필요, 충북 필터 목록의 근거로만 썼다. 표본 값 대조는 이번 대조 스크립트의 실행 결과로 판정했다.
- **원본 행 연결:** API 응답에는 `source_row_number`와 원문 지역 필드가 없다. 그래서 ID 일치로 v1.4 행을 특정하고, 원본과의 연결은 W-06 결과를 따른다(`공단 원본 → v1.4`는 W-06, `v1.4 → API`는 W-09).
