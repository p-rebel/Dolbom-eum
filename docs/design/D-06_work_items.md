## 실행 구성과 H-03 인계

시연 구성은 React·TypeScript·Vite 화면, FastAPI 서버, 로컬 디스크 SQLite 한 개다. 개발 때 Vite에서 `/api`를 서버로 전달하고, 팀 시연 때는 한 앱 출처로 제공한다. 양이수와 김재현이 11월 11일 실제 실행 버전과 의존성 잠금 파일, 재실행 명령을 고정한다. 기본 검증은 각자 로컬에서 실행하고, 팀 공유 접속은 운영 환경·접근 통제 결정 후 추가한다. [Vite 시작 가이드](https://vite.dev/guide/) · [FastAPI 시작 가이드](https://fastapi.tiangolo.com/tutorial/first-steps/) · [SQLite 트랜잭션](https://sqlite.org/lang_transaction.html)
