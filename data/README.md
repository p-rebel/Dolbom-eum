# data 폴더 안내

전체 설명(출처, 이용조건, 필드, 주의사항)은 상위 폴더의 `README.md`에 있습니다.

| 폴더 | 내용 |
|---|---|
| `raw/nhis/` | 국민건강보험공단 통합돌봄 서비스 자원 원본 CSV(CP949, 수정하지 않음) |
| `raw/local_menus/` | 지자체 메뉴판 PDF 234개의 출처 목록. 원본 PDF는 이용조건 확인 전이라 포함하지 않음 |
| `interim/pdf_extracted/` | PDF 추출 중간 결과 중 통과 판정 PDF 175개분(9,945행)과 원본 연번. 보류(`held/`) 파일은 제외 |
| `processed/` | 최종 정제 CSV v1.4. NHIS 90,081행, 지자체 서비스 12,725행(PDF 234개 전체) |
| `samples/` | 개발 참고용 샘플 JSON(전체 데이터 아님) |

- `raw`는 원본 그대로 보존합니다.
- `interim`은 추출·중간 결과, `processed`는 정제 완료 데이터입니다.
- NHIS와 지자체 데이터는 병합하지 않았습니다.
