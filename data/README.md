# 돌봄e음 데이터

국민건강보험공단 통합돌봄 서비스 자원 데이터와 전국 지자체 통합돌봄 서비스 메뉴판에서 추출한 데이터입니다.

## 폴더 구조
| 폴더 | 역할 |
|---|---|
| `raw/` | 원본 데이터(수정하지 않음) |
| `interim/` | 원본에서 추출한 중간 처리 데이터 |
| `processed/` | 매칭·정제를 마친 최종 데이터(예정, 현재 비어 있음) |

## 주요 파일
| 파일 | 용도 |
|---|---|
| `raw/nhis/국민건강보험공단_통합돌봄 서비스 자원_20260630.csv` | NHIS 서비스 자원 원본(공공데이터포털, 이용허락범위 제한 없음) |
| `raw/local_menus/source_list.csv` | 지자체 메뉴판 PDF 234개의 출처(게시글·첨부 URL, 수집일, SHA-256)와 GitHub 포함 여부 |
| `interim/pdf_extracted/nationwide_combined.csv` | 메뉴판 추출 데이터(통과 판정 PDF 175개, 9,945행) |
| `interim/pdf_extracted/held/*.csv` | 메뉴판 추출 데이터(조건부 판정 PDF 59개, 2,776행). 위 파일과 같은 18열 |
| `interim/pdf_extracted/serial_map.csv` | 일부 지자체 행의 원본 연번(통합 CSV에는 연번 열이 없음) |

## 데이터 처리 현황
- PDF 234개(17개 시도, 229개 시군구)에서 12,721행 추출, 최종 검증 완료
- 일부 원본의 병합 셀, 공란, 다중분류 같은 구조적 특성을 원본 그대로 반영
- 조건부 판정은 이런 원본 구조나 같은 시군구 중복 PDF 등의 특성 때문이며, 미해결 추출 오류를 뜻하지 않음

## 데이터 관리 원칙
- `raw`는 원본 그대로 보존하고, 출처 정보를 함께 유지합니다.
- `interim`은 추출·중간 처리 데이터, `processed`는 향후 매칭·정제 완료 데이터를 둡니다.
- 메뉴판 PDF는 이용 조건(공공누리 등) 확인 전이라 원본 대신 출처 정보만 제공합니다.

## 향후 작업
NHIS 데이터와 지역별 서비스 메뉴판 데이터의 구조를 분석하고 매칭할 예정입니다.
